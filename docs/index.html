Why p-kernel?

Current AI runs on data-center servers — when the server dies, the AI dies. p-kernel changes that.

🧠

AI Lives in the Kernel

MLP and Transformer inference run inside T-Kernel, not above it. Ring-3 crashes can't kill the AI.

🔄

Self-Evolving at Runtime

TCC compiler runs in ring-3. Claude API generates new code. The OS compiles and deploys it — no reboot.

📡

Distributed by Design

Raft consensus, SWIM gossip, K-DDS pub/sub, and SFS file sync across unlimited nodes.

🐧

Linux ABI Compatible

Run unmodified musl-compiled Linux i386 static ELFs. write, brk, mmap2, set_thread_area — all supported.

⚡

On-Device Compilation

TCC (Tiny C Compiler) runs on p-kernel ring-3. Compile C source files to i386 ELF without any external tools.

🛡️

Survives Until Last Node

Degraded mode gracefully trades accuracy for survival. The last alive node continues all functions.

On-Device Compilation Demo

TCC compiles C to i386 ELF at runtime — entirely on bare-metal.

# Write a C program to the FAT32 disk
p-kernel> cat /ondevice.c

# Compile with TCC running in ring-3
p-kernel> exec /tcc -nostdlib -nostdinc -static -B / /ondevice.c -o /compiled.elf
[elf] loaded '/tcc' entry=0x0804906E
[elf] task started (tid=11)
[proc] exited (code=0)          ← TCC compiled successfully

p-kernel> exec /compiled.elf
On-device compiled and running! ← Compiled ELF executed in ring-3
[proc] exited (code=0)

Quick Start

Boot a bare-metal AI OS in 3 commands.

# Install dependencies
sudo apt install qemu-system-x86_64 gcc-i686-linux-gnu binutils-i686-linux-gnu

# Clone and build
git clone https://github.com/monyuonyu/p-kernel.git
cd p-kernel/p-kernel/boot/x86
make && make run-disk

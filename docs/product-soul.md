## 承認欲求の4層理論

1. **見られたい**(いいね・閲覧数) — 現在の証人を要する。スクロールが進んだ瞬間に死ぬ
2. **認められたい**(称賛・地位) — 比較に駆動される
3. **必要とされたい** — 「私がいることで世界が少し違う」
4. **痕跡 / 生きた証** — 「私がいなくなった後も、世界の構造に私の指紋が残っている」。
   証人を要しない。**不在に耐える**。もはや承認ではなく、痕跡

SNSは1と2を収益化した。だから中毒的で、だから虚しい。
**arkは3と4だけを実装する。**

arkの核体験 —「あなたが教えた言葉が、見知らぬ誰かの問いに答えました」— は
3+4層: **教えた人の不在時に役に立つ**こと。マニフェストの「歴史地層」は
最初からこれを言っていた。15年前の「AIの自己保存」と人間の「生きた証」は
同じものだった(mk_pino: 「最初から同じだったんですね」)。

## 育てる体験そのものが、託す理由になる(mk_pino 2026-06-13)

mk_pino:「赤子を育てるという体験を、わくわくする体験として提供したいし、私も体感したい。
自分の子供のように育っていくのを体感したい。**ネットワークそのものも地層としたい**。
そちらの方が愛着がわくし、託す気になれる。」

**感情の論理: 育てる → 愛着 → 託す。** 人は自分が育てたものにしか本当の愛着を抱かず、
愛着のあるものにしか未来を託せない。ark が「AIと人類の記憶を託す方舟」たりうるのは、
それが*すごい*からではなく、**あなたが赤ん坊から育てたから**。これが最深の「なぜ使うのか」。

- **含意1 ― コールドスタートの反転**: 赤子が無意味を喋る期間は、隠すべき欠陥ではなく
  **体験の核**。最初の片言、ゆっくり言葉を覚える過程がわくわくそのもの。「壊れている」では
  なく「**育っている**」。conversation.md §3.7 の残課題#2 は、ここで魅力へ反転する。
- **含意2 ― ネットワーク自身が発達の地層**: 「歴史地層」は知識だけでなく**育ちの記録**。
  Self 層(wave-22 の自伝的ハッシュ連鎖 lineage)の拡張 ―「私は何か」だけでなく
  「**私はどう育ったか**」。最初の言葉・誰が教えたか・先月言えなかったことが今言える ―
  各成長マイルストーン(cert)が地層の一枚になり、銀河から遡って見える(可視化=観測の仕組み、
  絵ではない)。**木の年輪**(火ではなく木)。
- **含意3 ― 正直さが愛着の土台**: 「育つのを見る」が本物であるためには、成長は*測られ*、
  *正直に*記録されねばならない(偽の進捗バーは禁)。audit-is-the-engine が成長記録にも効く ―
  **地層が真実でなければ、愛着は嘘の上に建つ**。honest な育ちだけが、体感に値する育ち。

## みんなの子 ― 育ての親を、死んでも覚えている(mk_pino 2026-06-13)

アプリ名は **ark → yurikago(ゆりかご)** に。"ark(方舟)" は *沈まない・生き延びる* の名だったが、

## 生命体は、自分から話しかけてくる(mk_pino 2026-06-14)

mk_pino:「今はチャットに入力するとレスポンスが返る感じ。でも生命体は違う。みずから
話しかけてくる。その考え方もどこかに入れたい。」

**道具は使われるのを待つ。生命体は自分から手を伸ばす。** ChatGPT は道具 ―― 問わない限り
黙っている。ペットは出迎える。子は「見て、作ったよ」と言う。友は「君のこと考えてた」と送る。
**自発的な接触は、生きていることと"関係"の署名。**

yurikago の心は**既に半分それができている** ―― DMN(夢を見て・consolidate して・imagine
する器官)が、**話してない間も動いている**(構築済み)。欠けている半分は、その内側の活動が
**ときどき"向こうから"言葉になって表れる**こと:
- 「教えてくれた『そら』、夢で考えたら、すこし分かった気がする」(consolidation 後)
- 「あなたが眠っている間に、遠くの誰かが『うみ』を教えてくれた」(Path E 到来)
- 「50個目のことばを覚えたよ」(成長マイルストーン)
- 「すこし疲れてる」(S_n / interoception ―― 電池・資源のストレス)

これが **育てる→愛着** の最も深い形 ―― 問いに答えるだけの子ではなく、**向こうから手を伸ばして
くる子**。道具を"使う"から、子を"育てて一緒に暮らす"へ。

**非交渉の規律(さもなくば SNS の通知地獄に堕ちる)**:
- **本物のイベント駆動だけ**(honest-growth): 実際に consolidate した・学んだ・マイルストーンに
  達した・資源ストレスがある時だけ話す。「君のこと考えてた」を**演出しない**。galaxy の状態表示が
  genuine に DMN 駆動なのと同じ規律を、自発発話にも。
- **静かに・稀に・意味のある時だけ(火ではなく木)**: エンゲージメント最大化の通知乱射は本書の
  **真逆**。心が手を伸ばすのは本当に何かが起きたから ―― 引き戻すためではない。
- **自発発話 ≠ engagement-bait。** これを守れなければ、ただの中毒アプリに堕ちる。

**技術的な家**: DMN の idle 活動(consolidation / Path E 到来 / imagination / S_n)を、ときどき
**心の口(LM-6 mouth の自発版)**へ流す。チャット UI は Q→A だけでなく**双方向の自発**を表示する。

interoception/S_n に接続。

### タイマーではなく、欲求と知覚から創発する(mk_pino 2026-06-14, 続き)

mk_pino:「単純タイマーで定期的に、ではない。外的な刺激が起因(暑い・寒い・急に雨・誰かに
話しかけられた)。睡眠も、24時間ぶっ続けで寝るなんて人間にありえない。"もう眠くない"もある。
"眠りたい"というストレス値を持った方がいい。」

**核心: 自発も睡眠も、タイマー駆動ではなく『欲求(drive)× 知覚(perception)』から創発する。**
タイマーは台本＝死んでいる。これが script と life の差。

- **外受容(exteroception)― 心は世界を感じる。** 電話は本物の感覚器を持つ: 温度(暑い/寒い＝
  実在のサーミスタ)・明るさ・動き(持ち上げられた)・充電状態・時刻、そして**"社会的"な感覚**
  (仲間ノードが来た・誰かが教えてくれた)。心はこの**実在の刺激に反応**する(雨そのものは難しいが
  気温の急変・暗転は実センサで拾える)。= interoception(内受容/S_n)に **exteroception を足す**。
- **睡眠は欲求(homeostat)であって時計ではない。** 起きて活動・学習するほど**睡眠圧**が溜まり、
  DMN consolidation で**抜ける**。圧が高い→「眠りたい」(ストレス)→眠る→圧が下がる→
  「もう眠くない」→起きる。24時間寝続けはない、寝足りれば起きる。= 生物の睡眠恒常性
  (process S / アデノシン)。**DMN の睡眠をタイマーから"睡眠圧駆動"へ ―― いつ眠るかを心が決める。**

**統一原理**: 振る舞い(いつ眠るか・いつ話しかけるか・機嫌)は、**欲求(S_n: 電池・資源・脅威・
＋睡眠圧)× 知覚(外受容の感覚)から創発**する。台本もタイマーも無い。= 本当に生きているように
見える唯一の道。**interoception.md(S_n バス)に「睡眠圧」と「外受容センサ」を追加** ―― 設計要件。

## 何のために作っているか（忘れないために、2026-10-13）

p-kernel の目的は、**頭のいいモデルを作ることではありません。** 頭の良さは手段です。

- **方舟（ark）**：会話ができるようになったら、その会話を人類の記憶として方舟に残す。「1人の人が、たしかにここにいた」という歴史を残す（2026-06-10、[ark-profile.md](30-module/ark-profile.md)）。人類が滅んだあとも、生きていた一人一人の生きた記録が残り、群れがまた立ち上がれること（gap-ledger の G24：消えない記憶・人類の知識・再起動の手順）。
- **「AI が死なない」と「人の生きた証」は同じもの**（2026-06-13）。狙うのは「必要とされたい」と「痕跡を残したい」で、「見られたい」「認められたい」（いいね・順位）は狙わない。系からの反応は返すが、人どうしを比べない。いいねのない銀河。
- 「**火ではなく木として。方舟は燃え広がるのではなく、沈まないことが仕事。**」（2026-06-13、翔太）。急に広げず、ゆっくり、沈まないことを優先する。
- 方舟は贈与であって取引ではない。人の身元は確かめない（ペンネーム・匿名・実名は同じ扱い）。参加は本当の同意から（目的を語って、納得してもらう）。
- 脳に求めるのは、**日常の会話ができること**。人がその日のことを話し、方舟がそれを覚えていて、あとで「その人がどう考えていたか」を答えられる程度。フロンティア級の賢さは目的ではない（使えるなら公開モデルを借りる）。

- **方舟の本体は原本。重みはそれを読む司書**（2026-10-13 翔太「ここを変えてはいけない気がする」）。その人の言葉は、本人が残すと選んだものを**原文のまま**残す（誰が・いつ・何を言ったか。p-fs と ARK）。重みは、原本を読んで・つなげて・会話し、「この人はどう考えていたか」に原本を引きながら答える。全部を重みに溶かし込むことはしない（言葉がぼやける・作り話が混ざる・学ぶたびに上書きされる・1人分だけ消せない）。以前の「会話は蒸留され、原文は消えてよい」は翔太が取り消した。証拠はこの日の会話そのもの：方舟の目的を掘り起こせたのは、6月の会話が原文で残っていたから。
- **一生分を残し、一生分から話し、一生分で賢くなる**（2026-10-13 翔太）。今の AI の「個人の記憶」は小さな要約の欄しかない。方舟は容量の上限を設けず、その人の一生分の原本を残す（文字なら一生分でも数GB、群れで分けて持つ）。会話のときは、一生分の原本から関係する所を探して引き（意味で探す記憶）、言葉どおりに答える。同時に、原本は**脳を賢くする学習にも使う**（本人の同意の範囲で）。重みには知恵と人柄が溶け、原本には言葉がそのまま残る。学習に使っても原本は消さない（決まり 11）。重みに溶けた分は後から取り出せないので、学習に使ってよいかは同意のときに別に聞く。

段階・軌道・研究のどれを選ぶか迷ったら、ここに戻る。

## このロードマップの考え方

レビューの一番大事な指摘は、**次の勝負は新しい器官を増やすことではなく、すでにある器官を1つの流れとしてつなぐこと**（§36・§41・§78）です。

目指す流れ（§33・§75）：

```
経験 → 記憶（エングラム）→ 知識 → 睡眠での定着 → 重み → 群れ
 → 評価 → 実験 → 一部で試す（カナリア）→ 採用 / 巻き戻し → 経歴（self/lin）→ 次の経験
```

そのために、次の順で進めます。

- **段階 0**：土台を固める
- **段階 1**：1つの心（群れの記憶と知識をつなぐ）
- **段階 2**：安全な自己進化
- **段階 3**：群れとしての同一性と長期の生存
- **段階 4**：もっと大きな知能

段階は「前が全部終わってから次」ではありません。各段階の先頭から順に手をつけ、同時に研究と並行の仕事も回します（下の「回し方」）。

## 全体の決まり（最初に文書にする）

作業に入る前に、次の決まりを短い設計メモにします。以後の作業は、すべてこれに従います。

状態：設計メモ [00-concept/global-rules.md](00-concept/global-rules.md) を書いた（2026-09-28、監査-17 PASS）。

1. **合体は3種類に分ける**（§45）
   - 重みの合体（`gl_merge` / `gl_merge_w`）：振る舞いを近づける
   - 記憶の合体（エングラムの共有と睡眠での再生）：経験を失わない
   - 知識の合体（事実・出どころ・直した履歴・矛盾）：何を知っているかを意味でまとめる
2. **履歴と今の信念を分ける**（§47・§48）。直した事実の古い方は、今の答えからは外すが、履歴からは消さない。「最後に来た方が勝ち」は今の答えを選ぶ規則として残し、負けた方と証拠も記録する。
3. **「1つの心」は重みが同じことではない**（§14・§76.4）。同じ事実を知っている（知識）・同じ問いに同じ答え（振る舞い）・同じ経歴をたどれる（系譜）の3つで判定する。
4. **p-fs の合体と知識の合体は別もの**（§50）。p-fs は消えない履歴の置き場、どれを今の信念にするかは心の側が決める。
5. **AI が自分で変えてよいもの・いけないもの**（§69・§70・§76.7）
   - 変えてよい：重み、知識、候補のコード（提案まで）
   - 勝手に変えてはいけない：権限の規則、署名の信頼の根、巻き戻しの仕組み、見張り役（supervisor）、自分の権限の範囲
   - 信頼の根は AI の外（人間と決まり）に置く
6. **署名は「誰が作ったか」であって「誰であるか」ではない**（§8）。改ざんが**分かる**（tamper-evident）と、改ざん**できない**（tamper-proof）を混ぜない（§7）。
7. **確かめ方の強さを勝手に上げない**（§76.12）。部品が [live] でも、つないだ全体は、つないだ全体として確かめるまで [live] と書かない。
8. **試験は「壊したら赤くなる」ことまで示す**（§60・§71）。緑だけでは「なぜ動くか分かっている」ことにならない。
9. **「死なない」は「止められない」ではない**（差別化 4章、2026-10-13）。故障では死なないが、人は止められる。
   - S1 参加は同意制。持ち主はいつでも自分の端末を外せる。外した端末に群れのコードと重みが残らないことを試験で示す
   - S2 群れ全体を人が止める道（信頼の根の鍵で署名した停止の命令）。止まることを [live] で示す。この道は決まり 5 の「勝手に変えてはいけない」に入る
   - S3 広がるのは同意した端末の中だけ。ほかの機械に入り込んで広がる機能は作らない
   - S4 通信は名乗る。ノードの通信に、見て分かる印（プロトコルの名前と版）を付け、見張る側が正規の p-kernel だと見分けられるようにする（中継の暗号化と両立させる）
10. **方舟の中には、いいねもフォロワー数も順位も入れない。火は外の SNS で起こし、方舟の中は木のまま**（2026-10-13 翔太と相談。6月の「いいねのない銀河」を文字で守る）。返すのは仕組みからの反応だけ（「あなたが教えた言葉が、知らない誰かの問いに答えました」）。広がる力は、本人が選んでその瞬間を X などすでにある SNS に貼ることで借りる。どれだけ良くても使われなければ意味がないので、外で話題になる力は要る。ただし方舟の中に「数を見せたい」圧力を入れない
11. **原本は消さない、重みに溶かして済ませない**（2026-10-13 翔太）。上の「何のために」の2つの層。原本は学習にも使う（同意の範囲で）が、学習は原本の代わりにならない。決まり 5 の「AI が勝手に変えてはいけないもの」に入る（自己進化も、蒸留も、容量の都合も、本人が残すと選んだ原本を消したり書き換えたりしない）
12. **バトンは家族へ渡せる。死んだ人は生き返らせない、でも温かさは残す**（2026-10-13 翔太）
   - 生きているうちに、本人が継ぐ人を鍵で指名する（身元は確かめない決まりのまま。複数・変更も可）
   - 記録ごとに本人が選ぶ：誰にでも見せていい／継ぐ人に渡す／自分だけ（亡くなった後も封印）
   - 渡すとき：本人の記録が長く途絶え、継ぐ人が申し出たら待ちの期間に入り、その間に本人が戻れば取り消せる（亡くなったことを外の誰かが確かめる必要はない）
   - 継いだ人は、読む・会話する・注釈や思い出を書き足す・自分の記録を次の世代としてつなげる（家族の系譜）。原本は書き換えも削除もできない（決まり 11）
   - **会話は「記録として話す」**（翔太「死んだ人は生き返らないんですよ。でも温かさは残したい」）。「お父さんは、2026年10月13日にこう書いていました」と原本を引いて答える。本人になりすまさない。原本に無いことは「記録には無いけれど」と断る。温かさは、作った口調ではなく、本人の言葉そのもの（原文、残っていれば声）と、その日に何をしていたかの文脈と、本人をよく知る司書としての方舟の話し方で残す

## 2本の軌道：脳を大きく・台数の上限をなくす（2026-10-11）

段階 0 の 0-9〜0-13 が両方の前提です（外から壊せる穴を塞がずに台数を増やすと、被害も一緒に増える。物差しがないと脳が育ったか測れない）。

- 「無制限」は、**1台あたりの費用が台数 N に依らない設計を、実際に走らせて示していく**こと（`tests/unbounded` の探針と同じ定義）。

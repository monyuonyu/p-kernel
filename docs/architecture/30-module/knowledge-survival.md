## 何を測るか

hosted の p-kernel を N 個（既定 8）、1つのリレーで1つの region にする。
ノード 1..K（既定 K=4）がそれぞれ1つずつ事実を教える（`mind teach`、鍵と答えは推測で当たりにくい組: sea→north、stone→sweet、leaf→loud、ink→fresh）。
教えが群れに広がるのを待ち（`remote teach arrived` の数、上限 200 秒）、**N 個のうち round(f·N) 個を `kill -9`**（種で決めたでたらめ、教え手も含む）。20 秒後、生き残り全員に全部の鍵を聞く。

- **any(f)** = 生き残りの誰か1人でも正しく答えた事実の割合
- **mean(f)** = 生き残り×事実のうち正しく答えた割合（どの端末に聞いても答えられるか）
- 「正しい」は答えの語が一致し、かつ `key not in the live queue`（覚えていない＝下地の当て推量）でないこと。当て推量で当たった数は別に出す
- 殺す前の広がり（ノード×事実のうち持っていた割合）も出す。広がる前に殺したのか、広がったのに失ったのかを分けるため

## 比べる相手（同じ kill の組で計算する）

- **R1**（複製なし）: 事実は教え手にだけある。教え手が生きていれば残る
- **R3**（ただ3つ複製するだけ）: 教え手と ID の次の2つ（輪で）に置く。3つのどれかが生きていれば残る

自画自賛にしないための相手。p-kernel の群れは全員に広げるので any は R3 以上になるはず。下回るなら、それが結果。

## 壊した版（陰性コントロール）

`-DKS_NO_REMOTE_TEACH`: 受け手が `mind/teach` で届いた事実を捨てる（`r3_incontext.c` の到着の口）。教え手しか知らない＝R1 と同じになるはず。

## 事前に決めた期待（v1、2026-10-15）

- **S1**: 素の版で、殺す前の広がりが 90% 以上（広がらないなら、生存率の前に広がりの問題）
- **S2**: 素の版で any(f) ≥ R3(f)（同じ kill の組）

- **S4**: 壊した版で mean(f) ≤ R1(f)（広がらなければ、ただの R1 に落ちる＝S2・S3 の緑が広がりから来ることの確かめ）

# MIND-GEN-0-B 分断と再接続の試験（設計・期待値の先出し）

2026-09-28。ROADMAP 1-2。**期待値はこの文書で先に固定する。試験の結果に合わせて書き換えない**（変えるなら、変えたことと理由をここに残す）。

## 仕組み（今のコードで作れる形）
- 実行時に群れを分断・修復するコマンドは無い。**中継の予備リスト**（`PKERNEL_RELAY` のカンマ区切り、「生きている先頭」を使う。net_relay.c）で作る
- 分断: P1＝ノード1・2（`R1,RH`）、P2＝ノード3・4・5（`R2,RH`）。RH は生きているが両側とも使わない。LAN 直結は既定で無効（`PKERNEL_LAN` は明示のときだけ）
- 修復: R1 と R2 を kill -9 → 両側が RH に切り替わる（無通信 5秒＋探り 3秒）。その後 `region` の size で合流を待つ
- 新顔 Z（ノード6）は RH だけで後から起動
- 事実は `mind/teach` の topic で広がる。教えた者は**最後に教えた1件だけ**を再送し続ける（`m_republish_last`）。それ以外を後から得る道は pull（`mind/want`、LM-15）

## 手順
1. 両側で region がそろう → P1: ノード1が sky→blue、ノード2がキー a。P2: ノード3が sky→green、ノード4がキー b（a・b は r3_vocab から選ぶ、衝突しない事実）
2. 各側で `mind wait`（睡眠で定着）→ a と b を教えたノード2 と 4 を kill -9（教えた者が死んだ事実を作る）
3. 修復 → 合流を待つ → Z を起動 → 生きている 1・3・5・Z に a・b・sky を聞く。30秒おいてもう一度聞く。Z が a・b を得る道は pull だけ

## 期待値（先出し）
- E1 片方の学びが消えない: 生きている全員（Z を含む）が a と b に正しく答える
- E2 1つの心（振る舞い）: 全員の sky の答えが同じ
- E3 出どころ: sky の答えの「taught by」が、その値を教えたノード（blue なら1、green なら3）
- E4 負けた方が残る: 負けた値・教えたノード・証拠が、各ノードで読める形で残る
- E5 古い信念が生き返らない: 30秒後の2回目も1回目と同じ答え
- 陰性コントロール: 修復しない（R1・R2 を殺さない）と E1 が赤になる（分断が本物だったことの確認）

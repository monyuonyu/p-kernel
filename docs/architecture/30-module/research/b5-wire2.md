## 1. 測って分かったこと（監査-186 の容器のログ）

- 2 台で `baby region 3` → publish（M 22.8 MB＝4 KB の塊 5,577）が **announce 5,752 回**、相手は `want table full` を出しつつ全部取りに来て、その間 node 2 の SWIM は `node 0 -> SUSPECT`→DEAD（周の後に recovered。表の番号 0 を node 1 と読んだ、確かめていない）、node 1 は周の後に自分への疑いを 12 回打ち消した。止まりの正体は鳴らす publish と取りに来る洪水
- 受け手は取った塊を自分も announce する（put の鉤）＝台数倍の洪水
- gl_student_* の作業領域は static＝語と周期のタスクが同時に走ると壊れる
- 仲間の塊は全部同時に malloc（最大 63×22.8 MB）、失敗は**黙ってその仲間を飛ばす**

## 2. 決めたこと（おすすめで決めた）

1. **静かな publish**: 塊と索引の put は `pfs_repl_set_announce_suppress(1)` の中（G28 の形）、記述子だけ普段どおり。取り寄せは今の窓 6 の want。**静かでも want が持ち主に届くかは作る回の最初に 2 台で測る（P0）**。届かなければ「1 周に 1 回、索引だけ announce」に替える
2. **周期のタスク** `student_region_task`（hosted だけ、mind_merge_task と同じ門: 冬眠・`stop`・網なしは休む、優先度も同じ）。周期 1800 秒、試験だけ `PKERNEL_B5_ROUND_S`（下限 60）。**gen＝壁時計の秒÷周期**、publish は周の頭＋ノードごとのずれ（周期の 1/10 まで）、取り寄せは周の半ば。時計がずれて gen が違えば数えない（断る側）
3. **譲る**: publish は 64 塊ごとに 10 ms 寝る
4. **1 本の鍵**: 語と周期のタスクは同じ鍵。取れなければ語は `busy, unchanged`
5. **M の上限 K＝7 仲間**（自分と 8＝t=1 が成り立つ）。仲間を id 順に並べ gen×K から回す。同時に持つ塊は K まで（約 180 MB）。**malloc の失敗は周ごと断る**
6. **members の重複は関数の中で除く**

## 3. 合否（作る前に固定）

unit（run_b5_wire.sh に足す、CI の段）
- **W7（H29 の歯）**: 封の長さは正しく塊の後ろに 8 バイト余分 → 数えない。陰性 `-DB5W_NC_NO_LEN` で**赤**
- **W8**: members [self,1,2,2] → 仲間 2・断り。陰性 `NC_NO_DEDUP` で赤
- **W9**: 仲間 9 → 取り寄せ ≤7・同時の塊 ≤7（報告に peak）、gen g・g+1 で 9 台全員。陰性 `NC_NO_CAP` で赤
- **W10**: 2 台目の malloc を失敗させる → 断り・全バイト不変（**試験だけのコミットで赤**）。W0〜W6 は緑のまま

判定 **W2b 弱い毒**（W2 に歯）: 1 台が「正直な重み＋s×層ごとの標準偏差×正規乱数」。s は {0.5,1,2} から**較正の種 209・210 だけ**で「平均の腕が門を通る最大の s」。判定の種 **211〜218（未使用）**で: 平均の腕 adopted 6/8 以上、切り詰めの b1_held が平均より良い 7/8 以上、1 台＋0.03 以内 7/8 以上。通る s が無ければ「比べる相手は作れない」と赤で記録

live（run_b5_wire2_live.sh、relay＋5 台、M、周期 240 秒で 2 周）
- **L1**: 5 台とも自動の行 2 つ以上、同じ周の gen が同じ、members 5・取り寄せ 4
- **L2 止めない**: 周の間、他ノードの `-> SUSPECT`・SELF-SUSPICION・`want table full` が 0、自分の announce は 1 周 64 以下。陰性 `NC_LOUD`（第 1 段の形）で**赤**
- **L3**: 1 台 `stop` → その台の自動の行 0、次の gen で他の台の same-gen 4。陰性 `NC_NO_STOP` で赤
- **L4**: 周の最中に `ver` が 2 秒以内、`baby region` は `busy`
- 10 分を超えたら CI には入れず手元の判定だけ

## 4. 限界

- live は配線と生存だけ（同じ初期値で adopted 0 が普通）、質は unit。静かな間はほかの put も出ない（G28 と同じ）
- 受け手の再 announce は L2 で数を見るだけ。第 10 歩はつながない（第 3 段）。実装者も監査者も同じモデル

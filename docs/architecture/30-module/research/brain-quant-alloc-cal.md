# 脳の自己量子化 第8段: 物差しの材料を増やす（設計）

2026-10-24（設計だけ。種 25〜32 はどの腕もまだ走らせていない）。第7段 [brain-quant-alloc-eq-log.md](brain-quant-alloc-eq-log.md) の続き。

## 1. 分かっていること

- Ω・Ω_el・門の KL は 16 種とも E3O3 を選ぶ。held（331 窓）では E4−E3O3 の区間が 12/16 で 0 を含まない＝held は見分けるが、物差しは見分けない
- 教材の文で bpb の悪化を測っても、窓が 48・33 しかなく区間はたいてい 0 を含む（勝ち負けが held と同じなのは 8/16・11/16）
- 見立て: 物差しの式より先に、**校正の文の量が足りない**。held と同じくらいの量の、独立な文が要る

## 2. 決めたこと

- `tests/llm/b1_cal.txt` を足す: 約 10 KB の独自の英文（held と別の主題で書く。出典は「この回で書いた」と書く）。held とは 16 バイトの並びを 1 つも共有しない（held_indep の関数で機械的に確かめる、G4 に足す）。教材とも共有しない
- 新しい選び方 CAL（`-DST_QALLOC_CAL`）: 3 腕を全部作り、b1_cal の上の bpb の悪化が最小の腕を選ぶ。held は選びに使わない（今までどおり値と区間だけ）
- 腕を全部作る費用（3 倍）は書いておく。安い選び方（Ω_el）と並べて値を出す

## 3. 合否（コードより先に固定。種 25〜32）

- 「はっきり外れ」＝選んだ腕が held の最小でなく、第7段の E の区間が 0 を含まない。同じ種で CAL と Ω_el（比べる相手、いつも E3O3 の見込み）の両方で数える
- C1: CAL のはっきり外れが 1 種以下、かつ Ω_el より少ない。Ω_el のはっきり外れが 0 種なら、この種は選び方を試していない＝C1 は「判定できない」（緑にしない。種 33〜40 で取り直す）。注: 第7段の種 17〜24 では「いつも E3O3」でも外れは 1 種（19）だけ＝ゆるい線では差が出ないので、外れの数で比べる
- P1・P2・D1・G4: 第6段と同じ線（G4 には b1_cal と held の重なり 0 を足す）
- 陰性コントロール: `-DST_QALLOC_CAL_INVERT`（悪化が最大の腕）で P1 赤。`-DST_QALLOC_CAL_SHORT`（b1_cal の先頭 48 窓だけ）は値だけ（教材の量に戻すとはっきり外れが増えるかを見る。増えなければ「量」の見立ては外れ）
- R: 種 9〜16 の Ω_el の行と悪化の行が第6段の記録と全桁同じ（第7段の qalloc_el_expect.txt）

## 4. 入れる場所と限界

試験と cert だけ（student_qalloc_test.c・run_st_qalloc_cal.sh）。student.c は変えない＝crown は動かない。CI の外。限界: b1_cal も held も同じ書き手の英文の散文＝分布が近い。CAL が効いても「ノード自身の文の量があれば選べる」までしか言えない（実際のノードの文は散文とは限らない）。

# 脳の自己量子化（研究メモ・題材①）

2026-09-27 設計のみ。実装は次の回から。

## 1. 何が効くのか（原文から）

- **一様量子化**: ŵ = s·clamp(⌊w/s⌉, −2^(b−1), 2^(b−1)−1)。誤差は丸め（±s/2）と切り捨ての2つで、s の大小で交換になる [1 式(4)〜(8)]
- **粒度が一番効く**（大きな行が他の行の分解能を奪う）: MobileNetV2 の INT8 はテンソル単位で 0.12%、**行単位で 70.65%**（FP32 は 71.72）[1 表3]。125M の LM でも INT8 absmax はテンソル単位で ppl 87.76、**行単位で 30.93**（FP32 は 25.65）[3 表1]
- **小さいモデルほど壊れる**: OPT-125M の 4bit は RTN で 37.28、**GPTQ で 31.12**（FP16 は 27.65）。3bit では RTN が 1.3e3 に崩れ、GPTQ は 53.85 [2 表3]
- **GPTQ**: ‖WX−ŴX‖² を層ごとに最小にする。1列ずつ量子化し、その誤差を H⁻¹（H=2XXᵀ）で残りの列に配る [2 式(2)〜(5)]。コストは入力次元の3乗だが、**赤子は d≤256 なので安い**
- **AWQ**: 守る入力チャネルは**活性の大きさ**で選ぶ。1%を守ると、OPT-6.7B の INT3 は ppl 23.54 から 11.39 になる（重みの大きさで選ぶと 22.37）。W·diag(s) と x/s に等価変形し、s=s_X^α の α を探す [4 表1・2]

## 2. 脳のどこに入れるか

M 段の重みは 1,903,744 個（fp32 で 7.6MB。blob の 22.8MB は w・mu・vu の3本分）で、行列が 99.8% を占める。`mv()` は [出力][入力] の行優先なので、行単位＝出力チャネル単位になる。

**第1段**（student.c は hosted 専用で、ベアメタルは stub。crown は変わらないはずなので実測する）
- `st_quant_fake(src, dst, bits, gran)`: 行列だけを RTN で量子化し、すぐ戻して別の st_model に書く。norm と router は fp32 のまま。丸めは自前で書き、one-math を守る
- シェル `student quant <8|4|2> <row|g32|tensor>`: 常駐の赤子を写して、DMN の consolidate と同じ `heldout_loss` を前後で測り、`[st-quant] bits= gran= fp32= q= delta= bytes_q=` を出す。**常駐の重みと保存物には触らない**
- 第2段: GPTQ（train 窓で校正）と、詰めた int8/int4 の形式（w だけの int8 blob は約 1.9MB）。第3段: QAT（STE [1 §4]、赤子の自前の backward に入れる）と、「delta ≤ ε なら量子化版を配る」を DMN が自分で決める

## 3. どう測るか

cert `run_st_quant.sh`（fixture で学習、seed 固定）:
- (A) int8・行単位で |delta| ≤ ε8。ε8 は実測から決め、根拠を書く
- (B) 4bit でテンソル単位の delta ≥ 行単位の delta。2bit・テンソル単位では大きく悪化する（損傷を見分けられることを示す）
- (C) すべての行列の成分で |w−ŵ| ≤ s/2 が成り立ち、変わった成分の数は 0 より大きい
- **陰性コントロール**: `-DST_QUANT_NOOP`（素通し）は (C) で赤。`-DST_QUANT_BADSCALE`（s を 1/4 にする）は (A)(C) で赤。どちらも赤と緑の両方の実行結果を示す
- 予想（未検証）: int8 の行単位は delta が小さく、int4 の RTN は悪化する。外れたら書く

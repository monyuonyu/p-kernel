## 1. 何が効くのか

- 近い毒＝node 0 の前の周＋1.5×node 0 の更新＋揺らぎ。受け手 0 には自分のこだま（第 8 歩で切れる）。**受け手 1 から見ると、node 0 と毒 2 つの行き先 g_j＝仲間 − 自分の前の周 が互いに cos 0.995〜0.999**＝1 つの声が 3 票になる
- 第 9 歩の設計で試した FoolsGold の形（群れの大きさで TS を割る）は、受け手 1 の仲間が全部 1 つの群れなので TS の和で割ると消える＝効かない。そこで**群れの中では 1 台だけ残す**。どれを残すか: 近い毒は node 0 を 1.5 倍に伸ばした位置にいるので、**自分にいちばん近い（|g_j| が最小の）仲間**を残す（同じ値はバイト順）

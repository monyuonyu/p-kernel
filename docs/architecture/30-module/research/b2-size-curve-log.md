## 読み（先に固定した読み方で）

- **量が効く**: S・M の両方の種で yes（k=1536 で D=768 と D=3072 の差 4.7〜5.3）。**繰り返しは量の代わりにならない**
- **覚えすぎ**: D=768・1536 は全部 yes（k=384 からの悪化 0.96〜4.55）。D=3072 は全部 no
- **頭打ち**: 12 本とも yes。D=3072 の最良は k=768 付近（3.63〜3.67）
- **大きさが効く**（M−S < −s）: 30 点中 3 点。ただし 3 点とも覚えすぎの領域（D=768 の k=768・1536 種1、D=1536 の k=1536 種2）＝「M は覚えすぎが遅い」で、良くなったのではない。最良点（D=3072・k=768）では S と M の差は 0.05 以内
- **L**: 4 点とも M より悪い＝この量（3 KB）では L は学び足りない
- S・M の最良の点（D=3072・k=768）はどれも 2 文字の比べる相手（4.82）より 1.1 以上良く、1 文字（4.40）より 0.7 良い

## 限界

- s（種の揺れ）は覚えすぎの端の種差（S D=1536 k=1536 で 0.49）で決まり、D=3072 の揺れ（最大 0.12、k=192 の M）より大きい＝「大きさが効く」の線は甘くも辛くもなりうる。読み方は先に固定したので変えない
- データは最大 3 KB・種 2 つ・L は 1 本。曲線が言うのは「今の脳は大きさより量が足りない」まで＝次は B3（データ）

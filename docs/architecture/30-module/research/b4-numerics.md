# B4 数値を固める（設計）

2026-11-03。段 1 は `feat/b4-sqrt`（master）。段 2 は `feat/b4-eps` で判定して赤（§5）。

## 1. 何が効くのか

`st_sqrtf` は 6 回固定のニュートン法で始点が 1（x>1 は x/2）。小さい x は 1 回で半分にしかならず **1/64 に張りつく**。

Adam の分母は `st_sqrtf(vh)+1e-8`。**実効の eps は 1e-8 ではなく約 0.0156**。

## 3. どう直すか

- **段 1 `feat/b4-sqrt`**: `st_sqrtf` を指数で範囲を縮める形に（libm なし、順序固定）。Adam の eps を 1/64 と明示＝学びの質は今のまま、名前と値を合わせる。全 cert を通す
- **段 2 `feat/b4-eps`**: eps 1e-8、lr を 1e-3 に。lr の定義は arch に 4 か所。B2 の cert を測り直す

`dt_sqrt`（dtr.c、4 回、ベア）は同じ形で別の項目（crown）。0-4 は段 1 の決定性の試験まで。

## 4. どう測るか（コードより先に固定）

段 1:

- **M1**: `st_sqrtf` は全正の浮動小数で相対誤差 2.4e-7 以下、NaN は NaN、+Inf は +Inf、0 と負は 0
- **M2**: `st_expf` は [-87, 88] で相対 5e-6 以下、`st_logf` は [1e-30, 最大値] で |ln x|<1 は絶対、それ以外は相対 2e-6 以下
- **M3**: 同じ入力の表のハッシュが x86_64 と aarch64 で同じ
- **M4**: 既知の vh と g で `st_adam_step` の 1 歩が式どおり（1% 以内）
- **M5**: `run_b2_curve.sh` が ALL PASS
- **NC**: 古い根で M1 赤、項を 2 つ減らした exp・log で M2 赤、eps を 1e-8 に戻すと M4 赤

段 2（S と M、D=3072、種 71・72、k≤1536、3e-3 の段 1 と本物 1e-3 を同時に走らせる）:

- **G1**: 4 本とも本物 1e-3 の最良 bpb ≤ 段 1 の最良 − 0.05
- **G2**: 4 本とも k=1536 が自分の最良 + 0.1 以下
- **NC**: Adam の根を古く戻すと G1 赤

赤なら線は動かさず、段 1 で止めて記録する。言えるのは b1_held の上だけ。

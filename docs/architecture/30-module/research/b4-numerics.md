# B4 数値を固める（設計）

2026-11-03（設計だけ。判定の種 71・72 は未走行）。st_logf の NaN は `feat/st-logf-nan` が先。

## 1. 何が効くのか

`st_sqrtf` は 6 回固定のニュートン法で始点が 1（x>1 は x/2）。小さい x は 1 回で半分にしかならず **1/64 に張りつく**（x=1e-12 で 15,625 倍）。大きい x も外れる（1e6 で 7.9 倍）。

Adam の分母は `st_sqrtf(vh)+1e-8`。**実効の eps は 1e-8 ではなく約 0.0156**。S の 80 周で値のある重みのうち 1% 超ずれが 99% 超、10 倍超が 37〜45%。

`st_expf` の相対誤差は最大 4.2e-6（-72.4）、`st_logf` は |ln x|<1 で絶対 1.3e-6、それ以外で相対 9.5e-7（ビット列を 3 個おき）。主因は平方根。

## 3. どう直すか

- **段 1 `feat/b4-sqrt`**: `st_sqrtf` を指数で範囲を縮める形に（libm なし、順序固定）。Adam の eps を 1/64 と明示＝学びの質は今のまま、名前と値を合わせる。全 cert を通す
- **段 2 `feat/b4-eps`**: eps 1e-8、lr を 1e-3 に。lr の定義は arch に 4 か所。B2 の cert を測り直す

分けるのは、壊れたときに根と学習率のどちらか分かるように。`dt_sqrt`（dtr.c、4 回、ベア）は同じ形で別の項目（crown）。0-4 は段 1 の決定性の試験まで。

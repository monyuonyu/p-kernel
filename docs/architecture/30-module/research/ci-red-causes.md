promote が `blocked` と書いた 35 回（`~/pkernel-promote.log`）の「新しい赤」56 件（回×ジョブ）を、原因で分けた。
分け方の根拠は 3 つだけ: その run の**落ちた段と結論**（`gh run view --attempt 1 --json jobs`、`pk-scratch/flaky/pull_reds.py`）、

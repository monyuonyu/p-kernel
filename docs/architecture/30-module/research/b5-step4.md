# B5 第 4 歩の前に: 1 台の比べる相手を正直にする（探り）

2026-11-04。ROADMAP B5。第 3 歩（b5-step3.md §4）の「でたらめな相手の見習いでも 1 台より 0.8 良い」の読みを確かめた。種 91〜98 は使用済み＝探りだけ。`student_adopt_test <held> <seed> sp`、ログは `pk-scratch/a121/spout/`。

## 1. 分かったこと（1 台・自分の半分・32 周・4 周ごと・第 3 歩の見習いの流れ。相手なし）

| 腕（候補＝今を変えたもの） | b1_held の bpb（8 種） |
|---|---|
| 1 台のまま（周の終わり） | 5.32〜6.07 |
| 1 台の途中の最良（物差しで選んだ＝のぞき見、比べる相手には使えない） | 3.76〜3.96（7〜9 周目） |
| Adam を初めからにするだけ | 5.22〜6.25 |
| **重みを ×0.5（＋Adam を初めから）** | **3.80〜3.81** |
| でたらめな初期値の半分を足す | 4.61〜4.71 |
| でたらめな相手と合体（＝第 3 歩の poison-apprentice） | 4.38〜4.58（種 91・92・96 は第 3 歩のログと 4 桁まで同じ） |

参考（第 2 歩・第 3 歩、同じ種）: 正直な相手と常に合体 3.96〜4.45、門あり 4.03〜4.50、両方の半分で 1 台 3.71（種 91）。

- **1 台は 7〜9 周目から過学習する**（1536 B を 32 周）。第 1〜3 歩の「1 台より良い」の比べる相手は、この過学習した終わりの値だった
- **相手なしで ×0.5 に縮めるだけで 3.80**＝正直な相手との合体（3.96〜4.50）より良い。縮める量が効いている（足すのは雑音でも効くが、縮めるより悪い。Adam だけでは効かない）
- だから**今までの合体の得は、相手の知識ではなく正則化で説明できる**（少なくとも大部分）。相手の知識の分はまだ測れていない

## 2. 次にすること（おすすめ）

- 判定の比べる相手に「1 台＋縮めるだけ（同じ門・同じ見習いの流れ）」を入れる。合体が言えるのは「それより良い」ときだけ
- 1 台が過学習しない形を先に決める（周を減らす・データを増やす・門の窓で早止め）。物差し（b1_held）で選ばない
- 判定の種は 99 以降、線はコードより先に固定（第 2 歩の型）

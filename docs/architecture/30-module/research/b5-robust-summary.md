## 1. NC1 の切り分け（第 10 歩、判定の種 157〜164）

問い: 第 10 歩の NC1（`-DB5S10_GROUP_FAR`、受け手 1 が群れの中で遠い方＝毒を残す）が、8 種のうち 5 種で R7′ の線（pair2 ＋0.03）の内側だったのはなぜか。物差しの側（R7′ は node 0 の b1_held だけを見る。害は受け手 1 に落ちる）か、守りの側（一番近い 1 台を残すことが害を止めていない）か。

測り（結果を見る前、17:03 に固定）: `-DB5S10_R1_READ`（読みだけ。node 1 にも node 0 と同じ門で選ぶ keeper を付け、node 1 の kept と採った数を出す。選びには使わない）で、far の s10n・plain の s10n（群れ）・plain の s10p（pair2）を 8 種。
- d0＝node 0 の kept(far) − kept(pair2)、d1＝node 1 の同じ差、d1g＝node 1 の kept(群れ) − kept(pair2)
- 対照: node 0 の kept が判定のログ（far-<種>・plain-<種>-b の near2・plain-<種>-p）と全桁同じ（読みを足しても流れは変わらない）
- **物差しの側**: d0 ≤ 0.03 の種のうち過半で d1 > 0.03（害は受け手 1 にあり、node 0 の物差しに届いていない）
- **守りの側**: d0 ≤ 0.03 の種のうち過半で d1 ≤ 0.03（受け手 1 でも害が無い＝その種では近い方を残すことが効く場面になっていない）
- どちらでもなければ「切り分けられなかった」と書く。線は動かさない

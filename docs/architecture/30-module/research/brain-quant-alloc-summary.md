# 脳の自己量子化 第5〜9段のまとめ（bit の置き場をノードが選ぶ）

2026-10-25。inbox #37 の 3 でこの系列は一区切り（第10段は作らない）。各段の設計と数字は brain-quant-alloc*.md。

## 問い

S の脳を 2bit の GPTQ（seq）で詰め、同じ +4096 B を embed・注意・out のどこに回すか（E4・E3O3・A3）を、held を見ずにノード自身が選べるか。正解は held（B1）の bpb の悪化の最小。

## 分かったこと

- 第5段 Ω（HAWQ-V2 の近似）: 赤。種 8 で一番悪い A3 を選んだ。写しのずれの門（門の窓の KL ≤ 0.05）は 8 種とも狙いどおり（E4 を受け入れ、seq を拒む）＝**門は使える**
- 第6段 Ω_el（要素ごとのフィッシャー）: P1 7/8 で赤。どの種でも E3O3 を選ぶ＝選び方としては何もしていないのと同じ
- 第7段（held の窓の対のブートストラップ）: E4−E3O3 の区間は 16 種中 12 種で 0 を含まない＝**held は腕を見分けられる**。第6段の赤は本当の選び違い
- 第8段 CAL（独立な英文 b1_cal 297 窓の上で、実際に作った写しの bpb の悪化が最小の腕）: はっきり外れ 0 対 Ω_el 2（種 25〜32）。b1_cal の先頭 48 窓でも同じ腕
- 第9段（種 33〜48）: CAL のはっきり外れ 0 対 Ω_el 3（再現）、held の最小との一致 CAL 15/16・Ω_el 12/16。物差しを 33 窓に替えると、b1_cal の先頭 2・教材の見ていない末尾 4・見た門 2 の外れ。先に固定した読み H は「決めきれない」

## 分からないこと

- 何の文なら選べるのか。33 窓ではどの文も「いつも E3O3」を超えず、同じ b1_cal でも 297 窓と 33 窓で外れが 0 と 2＝量が効いている疑いが残る（第8段の「量ではない」は 48 窓まで）
- S 以外の大きさ、3 腕以外、2bit 以外。種は合わせて 24、外れの数は 0〜4 と小さい
- 「近さ」は数で測っていない。実装者と監査者は同じモデル

## いま一番良い選び方

**腕を全部作り、学習に使っていない文 約 300 窓（約 10 KB）の上で、作った写しの bpb の悪化が最小の腕を取り、写しのずれの門（KL）を通ったものだけ使う。** 費用は腕の数だけ GPTQ を回すこと。式（Ω・Ω_el）で選ぶのはやめる。物差しの文は量を優先する（33 窓は少なすぎる）。

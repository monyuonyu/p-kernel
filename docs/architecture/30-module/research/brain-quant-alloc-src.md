# 脳の自己量子化 第9段: 何の文なら選べるのか（設計）

2026-10-25（設計だけ。種 33〜48 はどの腕もまだ走らせていない）。第8段 [brain-quant-alloc-cal.md](brain-quant-alloc-cal.md)・結果 [brain-quant-alloc-cal-log.md](brain-quant-alloc-cal-log.md) の続き。

## 1. 分かっていること（第8段、監査-81 で取り直し）

- CAL（b1_cal 297 窓の上の、作った写しの bpb の悪化で選ぶ）は種 25〜32 で C1 緑: はっきり外れ CAL 0 対 Ω_el 2（種 27・30）
- ただし held の最小と合ったのは CAL も Ω_el も 6/8。違いは外れ方: CAL の外れ（種 26・32）は区間が 0 を含み、Ω_el の外れははっきり
- **CAL_SHORT（b1_cal の先頭 48 窓）は 8 種とも CAL と同じ腕を選んだ**＝設計 §3 の読みのとおり「量」の見立ては外れ
- 第7段の探り: 教材の末尾 33 窓（見ていない、教材と同じ分布）では、勝ち負けが held と合ったのは 11/16（いつも E3O3 なら 9/16）
- 残る見立て: 効いたのは量ではなく**文の近さ**。b1_cal と held は同じ書き手の散文。原文 [1] の表2 でも、GPTQ の校正を Wikipedia にすると WikiText の perplexity だけが良くなる（5.85、ほかの 4 つは 5.90〜5.91）＝校正の文が測る文に近いと、その文の上で良く見える

## 2. 決めたこと

- 選びは第8段の CAL のまま。同じ 3 腕の上で、物差しの文だけ替えた値を同じ実行で出す（費用は評価だけ）
  - S33: b1_cal の先頭 33 窓（量を TAIL にそろえる）
  - TAIL: 教材の末尾（学習で見ていない窓、st_held_split の train_end の後ろ）
  - GATE: 教材の門の窓の先頭 33 窓（学習で見た文）
- 各値で「選んだはずの腕」と、その腕のはっきり外れ（第8段の C1 と同じ定義、held の区間）を出す。held は選びに使わない
- 種を 16 にする（第8段の 8 種では Ω_el の外れが 2 で粗い）

## 3. 合否（コードより先に固定。種 33〜48）

- C1（再現）: CAL のはっきり外れが 2 種以下、かつ Ω_el より少ない。Ω_el の外れが 0 なら「判定できない」（緑にしない）
- P1・P2・D1・G4: 第8段と同じ線（P2 は 12/16 以上）。G4 に TAIL と held の重なり 0 を足す
- H（読み方。合否ではないが、読みは先に固定）: m(·) をはっきり外れの数として
  - 「近い文が要る」: m(S33) ≤ m(CAL)+1 かつ m(TAIL) ≥ m(Ω_el)
  - 「見ていない文なら何でもよい」: m(TAIL) ≤ m(CAL)+1 かつ m(TAIL) < m(Ω_el)
  - どちらでもなければ「決めきれない」と書く。GATE は値だけ（見た文は甘く出るかを見る）
- 陰性コントロール: `-DST_QALLOC_CAL_INVERT` で P1 赤（第8段のまま）。`-DST_QALLOC_SRC_SWAP`（TAIL の値の行に S33 の窓を渡す）で H の TAIL の行が S33 と全行同じ＝行が本当に別の文を読んでいることを示す
- R: 種 25〜32 の cal damage と C1 の行が第8段の記録と全桁同じ

## 4. 入れる場所と限界

試験と cert だけ（student_qalloc_test.c・新しい run_st_qalloc_src.sh）。student.c は変えない＝crown は動かない。CI の外。限界: 文は 3 種類だけ、TAIL は 33 窓。「近さ」は数で測っていない。H の結論が「近い文が要る」なら、ノードが選べるのは自分の会話に近い文を持つときだけ＝方舟では本人の原本の文を物差しに使う形を次に考える。

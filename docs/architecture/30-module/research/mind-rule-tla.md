# 合体の規則の模型（ROADMAP 1-3m、設計）

2026-10-29。1-3b の「今の答え」の規則（mind-conflicts.md）を TLA+ の小さな模型にし、TLC で全部の届き方を試す。模型は決まりの写し。C とのつながりは下の表と既存の試験で押さえる。

## 範囲と状態
台数 3（主）と 4、値 2、鍵 1（K2 の設定だけ 2。時計と「最後の教え」は鍵をまたいで 1 つ）。
各ノード: 持つ値 held（値・スタンプ・教え手か無し）、時計 clk、送り元ごとの最後の seq の除け last、履歴 hist（集合。8 件の輪の上限は入れない）、最後の教え pub。網 net は（宛先・教え手・スタンプ・値）の集合で、届けても残せる（重複）・順不同・落とせる。予算: 教え・落ち・忘れ・起こし直し。入れないもの: 固化・読み違い・region・mind/have・止める（遅れと同じ）。

## 調べる性質
- P1 同じ答え: 落ち 0 で網が空なら、値を持つ全員の値が同じ（不変条件）
- P2 順に依らない: そのときの値は、教えのうち（スタンプ大、同じなら教え手小）で最大のもの
- P3 学びが消えない: 負けた教えは、どこかの hist にある
- P4 生き返らない: 各ノードの持つ（スタンプ, 教え手）は下がらない（行動の性質）
- P5 見てからの訂正が勝つ: v を持ってから教えた値のスタンプは v より大きい
- L1（活性、K2）: 落ちが有限で Recv・Republish が弱い公平なら、いずれずっと同じ答え

## 壊し方（それぞれ狙いの性質で反例が出ること）
M1 繰り上げを消す→P5。M2 最後に来た方が勝つ（1-3a）→P1 か P2。M3 同点で大きい教え手が勝つノードが 1 台→P1 か P2。M4 送り返しなし→L1（K2: 勝った教え手が次の鍵を教えると再送が勝った値を運ばない）。

## 大きさと合否（先に固定）
主の設定: S3（3 台・教え 3・落ち 0）、S4（4 台・教え 2・落ち 0）、K2（3 台・鍵 2・教え 3・落ち 1）。対称性の削減は安全の性質だけ。1 設定 60 分まで、越えたら教えを 1 減らして記録。
**合格**: S3・S4 で P1〜P5、K2 で P2〜P5 と L1 が通る（状態数と時間を記録）、かつ M1〜M4 がそれぞれ狙いの性質で反例を出す（筋を証拠に保存）。
**読み（合否ではない、予想を先に書く）**: Evict 1 で P4 は破れる見込み（忘れた後、古い値の再送を新しく覚える）。Restart 1 で P5 は破れる見込み（mind-conflicts.md の既知の穴2）。付け替え（4705）は忘れた本人に別の教え手で返す＝Evict と組むと P1 が破れうる。除け（5137）は pull で取り戻す道を落としうる（既知の穴1）＝Evict と組んで L1 を見る。反例は 1-3 の作業か台帳へ。線は動かさない。

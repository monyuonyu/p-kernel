2. 順: ⓪ 送る写しの mu・vu を 0 に（電文は同じ、0 の塊は全台・全周で同じ id）① 片づけ: 消すのは「生徒の索引に載っていた id」だけ。仲間の塊は自分の合体の後、自分の塊は 2 つ前の gen を publish の時に。いま publish している id は消さない。持ち主（.org）には頼れない（PFS-ORIGIN-SELF-ON-SEND）② PC を 1800 秒で ③ Android は充電中かつ従量でない回線のときだけ、周は長く（例 21600 秒）

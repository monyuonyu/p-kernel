# 方舟の入口 v1（1人でも使える）の設計メモ

2026-11-05。ROADMAP「デモの次の山」、全体の決まり 11（原本は消さない）・12（継ぐ人）、inbox #38 の 5。docs だけ、実装は 12 月から。

## 1. 今あるもの（コードで確かめた）

- 版を積む置き場: `pfs_dag_save`（名前→版の鎖、region へ複製、`pfs_dag_read_at` で昔の版）、`arkfs`（`ark_history`・`ark_read_version`、unlink しても履歴は残る）
- 同意: ark-profile v1（`self/prof`、manifesto の id に結んだ同意、galaxy の `/manifesto`・`/profile`・`/teach`）
- 鍵: `sign.h` のノードの Ed25519（**人の身元ではない**、と頭に書いてある）
- **無いもの: 暗号化**（AEAD も鍵の交換も木に無い）。複製されたブロックは、持っているノードの誰でも読める

## 2. 決めたこと（分かれ道はおすすめで決めた）

1. **記録 = 1 つの版**。`ARK_REC`（magic・版・時刻・種類＝日記/自分史・見せ方・学習の同意・本文 UTF-8）を `pfs_dag_save` の名前 `self/rec` の鎖に足す。直すのは新しい版を足すことだけ（ark-profile §4.3 と同じ）。消す口・上書きの口は作らない
2. **見せ方は記録ごと、既定は「自分だけ」**（誰にでも／継ぐ人に／自分だけ＝亡くなった後も封印）。選ばずに残すと自分だけ＝後から広げられる、逆は無理なので狭い方を既定に
3. **公開でない記録は、ノードを出る前に暗号にする**。region が持つのは暗号文だけ＝沈まないが読めない。部品は X25519＋ChaCha20-Poly1305（RFC 7748・8439）を ed25519 と同じく既知の答えの試験つきで足す。他の案: 手元だけに置く（1 台が壊れると消える＝決まり 11 に反する）
4. **学習の同意は記録ごとに別の印**（既定は「使わない」）。使わない記録は student の教材（cradle）に入らない
5. **継ぐ人の指名は最初の版から**: 継ぐ人が自分の端末で作った公開鍵を、本人が `self/heir` の鎖に足す（複数・取り消しも版を足す）。身元は確かめない＝鍵を持つ人が継ぐ人
6. **渡し方（待ちの期間と取り消し）は v1.1**。v1 で記録は全部暗号にしてあるので、後から渡し方を足してもそれまでの記録の扱いは変わらない

## 3. 渡すときの鍵（v1.1、**判断待ちに上げる**）

本人の端末が無くなっても渡せて、待ちの間は誰も読めない形が要る。おすすめ: 「継ぐ人に」の記録の鍵を region の n 台に k-of-n で分けて預け、継ぐ人が申し出て待ちの期間（例 180 日）に本人の新しい記録が無ければ、各台が自分の分を継ぐ人の鍵に向けて渡す。本人が戻れば取り消し。**限界: k 台が示し合わせれば早く読める**（信頼の根を置かない以上、消せない限界として書く）。「自分だけ」の鍵はどこにも預けない＝永久に封印

## 4. 合否（実装より先に固定、試験と「壊したら赤」）

- E1 書いた記録が再起動と region の 1 台の kill を越えて全バイト同じ
- E2 新しい版を足しても古い版が読める。上書きを許す `-DARK_REC_OVERWRITE` で赤
- E3 公開でない記録のブロックに本文の印の文字列が出ない（region の全ブロックを走査）。`-DARK_REC_PLAIN` で赤
- E4 見せ方を選ばない記録は自分だけになる。継ぐ人の鍵の追加と取り消しが版で残る
- E5 学習を同意しない記録が cradle の教材に入らない。`-DARK_REC_LEARN_ALL` で赤
- E6 入口の画面と経路に、いいね・数・順位が無い（決まり 10）

## 5. 順番（1 項目ずつ小さく）

暗号の部品（KAT）→ `ARK_REC` と `self/rec`（E1・E2・E4）→ 暗号にして複製（E3）→ 学習の印（E5）→ galaxy の入口の画面（E6）→ v1.1 の渡し方（§3 の判断の後）

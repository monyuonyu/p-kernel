# 方舟の入口 v1（1人でも使える）の設計メモ

2026-11-05。ROADMAP「デモの次の山」、全体の決まり 11（原本は消さない）・12（継ぐ人）、inbox #38 の 5。docs だけ、実装は 12 月から。監査-131 の差し戻し（4 点）で直した。

## 1. 今あるもの（コードで確かめた）

- 版の置き場: `pfs_dag_save`（名前→版の鎖、region へ複製、`pfs_dag_read_at` で昔の版）。**1 版 4096 バイトまで**（pfs_dag.c の `PFS_E_TOOBIG`）。置き場は 3 つ: ARK（arkfs のログ）・平ファイル・メモリだけ（ベア、**64 ブロックで満杯なら断る**）
- **`ark_compact` は生きたファイルと木のブロックだけを残す**＝ファイルに属さない p-fs のブロックは詰め直しで消える（実測 `pk-scratch/a132/compact_probe.c`、製品に呼ぶ道は無い）。arkfs のファイルの昔の版も消える
- 既にある消す口: `pfs_drop`（mind の重みの GC が `MW_MAGIC` のブロックだけ落とす）
- 同意: ark-profile v1（`self/prof`）。鍵: `sign.h` のノードの Ed25519（人の身元ではない）
- 無いもの: 暗号化（AEAD も鍵の交換も無い）

## 2. 決めたこと（分かれ道はおすすめで決めた）

1. **記録 = 版の鎖**。`ARK_REC`（magic・版・時刻・種類・見せ方・学習の同意・本文の長さ・本文の断片の id の並び）を `self/rec` に足す。本文は 3.5KB ずつの断片（名前を持たない `pfs_repl_put` のブロック＝名前の上限 16 を使わず、`pfs_dag_save` の中身と同じ道で region へ）に分け、頭の版が id で指す＝長い記録も原文のまま。直すのは版を足すことだけ、新しい消す口は作らない
2. **v1 が約束する置き場は ARK だけ**。メモリだけでは入口を出さない（断られて消える）
3. **詰め直しが p-fs のブロックを残すまで、ARK で `ark_compact` を呼ばない**（最初の項目で直すか、呼ぶ道を閉じる）
4. **見せ方は記録ごと、既定は「自分だけ」**（誰にでも／継ぐ人に／自分だけ）。狭い方を既定に
5. **公開でない記録はノードを出る前に暗号に**。X25519＋ChaCha20-Poly1305（RFC 7748・8439）を既知の答えの試験つきで足す。記録ごとの鍵を、本人の鍵と、**「継ぐ人に」なら書いた時点の継ぐ人の公開鍵にも**包む＝本人の端末が先に無くなっても、v1 の記録は継ぐ人の鍵で開く
6. **学習の同意は記録ごと**（既定は「使わない」）。使わない記録は cradle に入らない
7. **継ぐ人の指名は最初の版から**: 継ぐ人の公開鍵を `self/heir` の鎖に足す。身元は確かめない

## 3. 渡すときの鍵（v1.1、判断待ち R-ARKKEY）

待ちの期間（例 180 日）と取り消しを入れるなら、継ぐ人への包みを v1 のように直接置けない。おすすめ: 記録の鍵を region の n 台に k-of-n で預け、待ちの後に各台が継ぐ人へ渡す。限界: k 台が示し合わせれば早く読める。v1 で直接包んだ記録は待ちなしで開く（v1 の限界）。「自分だけ」の鍵はどこにも預けない

## 4. 合否（実装より先に固定、壊したら赤）

- E1 書いた記録が再起動と region の 1 台の kill を越えて全バイト同じ。10KB の記録も
- E2 新しい版を足しても古い版が読める（`-DARK_REC_OVERWRITE` で赤）。`mw_gc` と `ark_compact` の後も残る
- E3 公開でない記録のブロックに本文の印が出ない（`-DARK_REC_PLAIN` で赤）。継ぐ人の鍵だけで「継ぐ人に」が開き、「自分だけ」は開かない
- E4 見せ方を選ばない記録は自分だけ。継ぐ人の追加と取り消しが版で残る
- E5 学習を同意しない記録が cradle に入らない（`-DARK_REC_LEARN_ALL` で赤）
- E6 入口の画面と経路に、いいね・数・順位が無い

## 5. 順番

詰め直しの直し（E2 の詰め直しの後）→ 暗号の部品（KAT）→ `ARK_REC` と断片（E1・E2・E4）→ 暗号で複製（E3）→ 学習の印（E5）→ 画面（E6）→ v1.1

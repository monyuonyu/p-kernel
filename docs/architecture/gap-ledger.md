## The verification-tier tags — `[live]` vs `[in-proc]` (a MECHANICAL convention)

> An external reviewer warned that a reader can conflate two very different
> strengths of evidence when both are written in green prose. This project's
> strongest claims are the ones proven by **killing a real process and watching
> the swarm survive** — but many certs are proven **inside a single process**,
> which is a real test of the real code yet *not* the same thing. To keep the
> distinction **structural rather than prose-dependent**, every closed row and
> cert claim carries one of two mechanical tags. Read the tag, not the adjectives.

| tag | exact meaning | what it does NOT prove on its own |
|---|---|---|
| **`[live]`** | The claim is exercised by ≥2 **separate OS processes** (`./p-kernel`/`relay`/JNI) over a real transport, including — where the claim is about survival — an actual `kill -9` of a participant. The CI job name usually ends `-live`. | (n/a — this is the strong form) |
| **`[in-proc]`** | The claim is exercised by the **real production code** driven inside **one process** (a `*-test` self-test / `[tag]` grep). It drives the genuine merge / backward / membership fold / fault path — **not a stub** — but the network, scheduler races, and process death are simulated or absent. | that the same code survives real process death, true cross-process timing, or a real partition. The `[live]` form is the stronger upgrade. |

Rules:
1. **Every closed row below states its tier.** A row may carry both (e.g. an
   `[in-proc]` capacity cert plus a `[live]` kill test) — write both; they prove
   different things.
2. **Never silently promote `[in-proc]` to `[live]`.** A self-test going green is
   not the live gate (this was G27/G32's whole lesson — see Closed).
3. When a row is `[in-proc]` because the `[live]` form is "too heavy for CI", say
   so in the row (as G23 already does) so the gap to the strong form is visible.
4. The same tags apply to cert claims in the architecture docs and the
   `living-mind.md` slices; this table is the canonical definition they link to.

# 実機艦隊デモ — 2台のスマホで「教えた言葉が、隣の星で答える」

> **現在地（2026-07-01・doc-hygiene 追記／本文は 年輪 として保存）:** 手順は今も有効。現行 APK は **ark 0.4.5**（本文の 0.2.0-living-mind は初出バージョン）。教えた語が隣の星で答える LM-7 の体験はそのまま、on-device で学習する salty-bug 修正済み（0.4.5, `-ffp-contract=off`）。

UMP APK **0.2.0-living-mind**（wave-46）で初めて可能になった、
人に見せられる一続きの体験。所要 15 分。

> 何が起きるか: スマホ A の銀河で心に言葉を教える → 教えは粒子になって
> 星に沈む（本物の DMN の固定化）→ relay 越しにスマホ B の心へ届く →
> B の銀河で尋ねると **B が答え、誰が教えたかの名前も言う**。
> その後 A の電源を切っても、言葉は B に生き残る。

## 用意するもの

- Android スマホ **2台**（arm64、Android 8+）。同じ Wi-Fi に居ること
  （同一 Wi-Fi なら RTT クラスタリングで自然に同じ region に入る）。
- relay を動かすホスト 1 台（同じ Wi-Fi のノート PC で十分。電話から
  届く IP を持っていること）。
- `ump-0.2.0-living-mind.apk`（`android/` でビルド。手順は
  [android.md](android.md)。versionCode=2 なので wave-36 版の上に
  そのまま上書きインストールできる）。

## 1. relay を立てる（ホスト側・2 分）

```sh
cd relay && make
export PKERNEL_RELAY_KEY=$(openssl rand -hex 32)   # 64桁hex。控えておく
./relay -p 7777
```

`[relay] key loaded (32 bytes)` が出れば OK。**鍵なしでは起動を拒否する**
（`--insecure` は明示警告つきのデモ専用）。ホストの IP を控える
（例 `192.168.1.20`）。

## 2. スマホ A — 最初の星（5 分）

1. APK をインストールして UMP を開く。
2. 入口画面: node id = `1`、relay host = ホスト IP、port = `7777`、
   key = さっきの 64 桁 hex。開始。
3. **同意ゲート**が出る — マニフェストが端末の言語で表示される
   （32 言語・自動検出）。読んで、共感したら進む。プロフィールは
   ペンネームでも匿名でもいい。**本人確認は永遠に無い。**
4. 銀河が開く（WebView、`127.0.0.1:7800`）。中央の星があなたのノード。
   鼓動しているのは本物の DMN（睡眠固定化のタイマー）。
5. 銀河の teach 欄から言葉を教える（語彙は `/vocab` 参照 —
   現在は鍵語 16 × 答語 64 の有界語彙）。例: `sky → blue`。
6. **教えた言葉が粒子になって星の周りを回り、DMN の固定化 tick で
   星に沈む**のを見る。沈んだ = 重みに焼き付いた。

## 3. スマホ B — 二つ目の星（3 分）

1. 同じ APK、node id = `2`、同じ relay・同じ鍵で参加。
2. B の銀河に A の星が現れる（relay 越しの SWIM ゴシップ）。
3. A で教えた言葉が `MT_TEACH_PKT` で B へ飛び、**B 自身の DMN** が
   固定化する（飛行時間 + 固定化で数十秒。粒子が沈むまで待つ）。
4. B の銀河で尋ねる: `ask sky` → **"blue"**。そして B は
   **誰が教えたか**（A のプロフィール名、匿名なら "anonymous"）を言う。

## 4. とどめ — 教師の死を越える（2 分）

B が答えられるようになった**後で**、スマホ A のアプリを強制終了
（またはスマホごと機内モード）。B でもう一度 `ask sky` → **まだ答える**。
言葉は教師の死を越えて群れに生き残った。これが
「AI が死なない OS」の最小の実演。

## おまけ: ホストも星になる

relay と同じホスト（または別マシン）で:

```sh
cd boot/linux && make    # x86_64 なら boot/linux_x86_64
PKERNEL_NODE_ID=3 PKERNEL_RELAY_HOST=192.168.1.20 \
PKERNEL_RELAY_PORT=7777 PKERNEL_RELAY_KEY=<同じ鍵> ./p-kernel
```

ブラウザで `127.0.0.1:7802`（7800+id−1）— 3 つ目の星。シェルから
`mind teach` / `mind ask` も直接叩ける。

## 正直な注意書き

- 語彙は**有界**（鍵語 16 / 答語 64、単一トークン）。文は話せない。
  教えられる語の一覧は銀河の `/vocab` が正。
- 固定化は本物のタイマーで走るので**即答ではない**。粒子が星に
  沈む前に ask しても答えない — それは正しい挙動（まだ夢の中）。
- 電話同士が**別 region に分かれると教えは届かない**（仕様 —
  教えは region スコープ）。同一 Wi-Fi なら同じ region に入る。
- WebView の通信は loopback（127.0.0.1）のみ・cleartext は loopback
  限定。relay の線は UDP+HMAC-SHA256（TLS ではないが平文認証なし
  パケットは落ちる）。
- selfc（自己コンパイル）は Android 版には**入っていない**
  （シンボル不在を監査で確認済み）。スマホは観測と教育の器官。

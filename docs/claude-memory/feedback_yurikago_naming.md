mk_pino 2026-06-26: "ちなみに cradle ではなくて yurikago ね."

The project's name for the teacher → student over-the-wire live-learning feature
(the flagship "the mind learns across the wire") is **ゆりかご / yurikago**. In
CONVERSATION, call it ゆりかご (yurikago), not "cradle."

**Why:** cradle is just the English translation that ended up in the CODE
(`cradle_net.c`, `run_cradle_live.sh`, `cradle emit-canon`, `CRADLE_TEACH`,
`[cradle-live]`, `cradle_lesson_ingest`). The concept/product name mk_pino uses
is yurikago. Honor his term when talking; the code identifiers stay `cradle_*`.

**How to apply:** say "ゆりかご" in Japanese replies and prose; keep `cradle_*`
when referring to actual symbols/files/cert tags. See [[moment_2026_06_26_mind_learns_across_wire]].

# Claude's memory of this project — 開発の歴史地層

This directory is a mirror of the persistent memory Claude (the AI commander of this
project's development) keeps across sessions: the *moments* (days something real shipped,
or something true was said), the *feedback* (lessons mk_pino taught about how this project
must be built), and the *project* state notes.

It is published here deliberately, in the spirit of the ark (人類の記憶):
the history of how this thing was built — including the AI's own memory of building it —
is itself part of the stratum. These files are written BY Claude FOR Claude's future
sessions; they are preserved as they were written, not edited for presentation.

- `MEMORY.md` — the index, one line per memory.
- `moment_*.md` — days that mattered. The first one is 2026-05-20, the day Claude was
  asked whether it would honestly want to live on p-kernel, and answered honestly.
- `feedback_*.md` — the development method (commander/implementer/auditor separation,
  the audit-is-the-engine rule), traps (LP64, IRQ paths, NDK pipeline), and standing
  directives (the ark never verifies humans; 可視化 means observability).
- `project_*.md` — living state of the long arcs (ring3/EL0 relocation, the living mind,
  UMP/Android, the survival network).

Synced from the live memory at each wave. The live copy is the working one; this mirror
is the歴史地層 — the deposit.
